## 游戏概述

| 项目 | 说明 |
|------|------|
| 类型 | 横版清关砍杀（Side-scrolling Beat'em up / Hack & Slash） |
| 题材 | 中国传统 · 幻想武侠江湖，水墨仙侠风 |
| 平台 | Web（PC + 移动端自适应），纯 HTML + JS，免安装 |
| 核心循环 | 选将 → 读关卡剧情 → 冲锋破阵（清版推进）→ 阵前单挑 Boss → 破阵结算 → 下一阵 |
| 胜利条件 | 击破第 10 阵「五丈原」守将司马懿 |
| 失败条件 | 气血归零（可续阵重来，保留已破阵数） |
| 单关时长 | 3–6 分钟 |
| 参考实现 | operation-ironhold（状态机/波次）、Beat_Fight_Game（清版战斗）、MarioMagic（空格跳跃）、YONGZHE（勇者成长节奏） |

### 游戏状态机

```
TITLE(标题) → CHAR_SELECT(选将) → STORY(关卡剧情) → PLAYING(破阵)
   ↑                                                    │
   │                                    ┌───────────────┼──────────────┐
   │                                    ▼               ▼              ▼
   │                              LEVEL_CLEAR       GAME_OVER       VICTORY
   │                             (破阵结算)        (兵败·续阵)     (天下归一)
   └────────────── 任意状态可返回标题 ──────────────┘
```

## 操作方式

### PC 端

| 按键 | 功能 |
|------|------|
| `A` / `D` | 左 / 右移动 |
| `W` | 跳跃（等同空格，可二段跳） |
| `S` | 下蹲 / 下落加速（空中） |
| `空格` | 跳跃（致敬 MarioMagic 的手感：短按小跳、长按大跳） |
| `J` | **普攻**（三段连击，第三段带击退） |
| `K` | **职业技能**（耗内力，华丽特效） |
| `L` | **破阵绝技**（耗怒气，全屏演出） |
| `Shift` | 疾跑 / 闪避（带无敌帧） |
| `P` / `Esc` | 暂停 |

### 移动端

- 左侧**虚拟摇杆**：移动 + 上推跳跃
- 右侧**虚拟按键**：`攻`(J) / `技`(K) / `绝`(L) / `跳`(Space)
- 自动检测触屏设备显示，PC 端隐藏

## 技术架构

**极致视觉方案**：渲染与物理解耦，混合渲染。

| 层级 | 技术 | 说明 |
|------|------|------|
| 背景渲染 | **Three.js**（透视相机 + 多层视差平面） | 3D 背景层：AI 生成的关卡原画贴于 PlaneGeometry，雾效 + 天光 + 余烬/落英粒子 |
| 游戏渲染 | **Canvas 2D**（正交，独立画布叠加） | 角色/怪物/Boss/刀光特效精灵层，帧率稳定、像素锐利 |
| 角色动画 | **Spine 骨骼动画**（spine-canvas 3.8，vendored） | 8 名角色 .skel/.atlas/.png 直接渲染到游戏画布（三角网格渲染模式） |
| 物理 | **Planck.js**（Box2D 官方 JS 移植） | 刚体/平台/推挤/击退冲量，布娃娃级打击反馈 |
| 动画 | **Sprite 帧动画 + Spine 特效帧序列** | AI 生成 sprite sheet（走/攻/跳/受击/死亡）；Spine 合集导出刀光/火焰/雷电帧序列做技能特效 |
| 特效 | Three.js 粒子系统 + Canvas 序列帧 | 打击火花、剑气拖尾、屏幕震动、Bloom 泛光 |
| 音频 | MiniMax music-2.6 BGM + WebAudio 程序化音效 | 动感打斗纯音乐；出招/命中/技能全音效 |
| UI | DOM + CSS（隶书标题/卷轴/印章） | 血条/怒气/连击数/关卡卷轴剧情 |
| 构建 | 无构建，原生 ES Modules | 静态部署，即传即玩 |

### 角色动画方案
角色采用本地 Spine 素材（`assets/spine/<id>/`：skeleton.skel + skeleton.atlas + skeleton.png 多页贴图），通过 vendored 的 **spine-canvas 3.8** 运行时直接渲染到 2D 游戏画布（`triangleRendering` 模式支持网格附件）。语义动画映射：idle/run/atk1-3/skill_a/skill_b/hit/die/fly。Spine 加载失败时自动降级为水墨程序化渲染器（InkWarrior），保证任何环境可玩。

特效采用 **「Spine 特效帧序列提取」** 方案：从 800+ 套特效合集中导出逐帧 PNG（刀光/火球/雷电/Boss 技能等），以 flipbook 方式播放。

## 打击感设计（Game Feel）

1. **顿帧（Hit-stop）**：命中瞬间冻结 60–120ms，重击/终结技更长
2. **屏幕震动**：位移 + 旋转双通道噪声震动，按伤害分级
3. **击退冲量**：Planck 刚体 `applyLinearImpulse`，第三段连击大击退
4. **粒子反馈**：命中火花 12–20 粒、血雾（水墨风朱砂点）、刀光拖尾
5. **受击闪白 + 缩放弹跳**：受击者 1 帧白闪，0.9→1.1 弹性恢复
6. **连击系统**：3s 内连续命中累计 Combo，≥10 连击伤害 +5%/级
7. **音效分层**：挥空/命中/破防三种音色，音高随连击数微升
8. **击杀慢镜**：Boss 击破 0.3× 子弹时间 800ms + 水墨定格

## 性能预算

| 指标 | 预算 | 手段 |
|------|------|------|
| 帧率 | 60 FPS（移动端 ≥45） | 固定时间步物理、离屏剔除、对象池（敌人/粒子/伤害数字） |
| 同屏实体 | ≤ 40 | 波次刷怪 + 死亡回收 |
| 粒子 | ≤ 500 | 单 emitter 上限 + 自动降级 |
| DrawCall | ≤ 120 | 精灵合批、背景 3 层平面 |
| 首屏加载 | ≤ 8MB | 背景 WebP 压缩、音频流式、懒加载后续关卡素材 |
